# 📖 Project Overview

This project presents a comprehensive financial and stock performance analysis of **Apple Inc.** using **Microsoft Excel, Google BigQuery (SQL), and Microsoft Power BI**. The objective was to transform raw financial statements and historical stock price data into meaningful business insights through data cleaning, SQL analysis, and interactive dashboard development.

The dashboard evaluates Apple's financial performance, profitability, asset management, and historical stock price trends from **2022–2025**, providing an end-to-end business intelligence solution for financial analysis.

---

# 🎯 Business Problem

Investors and financial analysts require reliable and interactive reporting to evaluate a company's financial health and market performance. Although financial statements and stock price data contain valuable information, they often require cleaning, transformation, and visualization before meaningful insights can be generated.

This project analyzes Apple's financial statements alongside historical stock prices to identify profitability trends, financial growth, and stock market performance over time.

---

# 🚀 Project Objectives

- Clean and prepare financial and stock datasets using Microsoft Excel.
- Perform financial analysis using Google BigQuery SQL.
- Apply SQL Joins, Aggregations, Window Functions, and Subqueries.
- Build an interactive Power BI dashboard for financial reporting.
- Analyze revenue, profitability, assets, liabilities, and stock performance.
- Generate meaningful insights for investors and business decision-makers.

# 💡 Key Business Insights

- Apple maintained consistent revenue growth throughout the analysis period.
- Net income remained strong, reflecting sustainable profitability.
- Gross and net profit margins demonstrated efficient operational performance.
- Total assets consistently exceeded total liabilities, indicating a healthy financial position.

- Revenue and average stock prices displayed a positive relationship over the selected years.
